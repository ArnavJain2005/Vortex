# Vortex: technical explainer video

A 2:11 standalone technical video: Arnav's talking head in a circle over code-built 2D animation (with three
small 3D moments), made in [HyperFrames](https://github.com/heygen-com/hyperframes). It is separate from the
60 s Pip film and is never joined to it; it shows two Pip stills only as a bridge (disclosed on screen).

## Downloads

**`video-v1`** (created as a draft; Arnav publishes it):

## Numbers on screen

Every number on screen comes from `Docs/NUMBERS.md` or the README and was checked by an independent pass:
−8.1 % APE and −40.2 % 1 s RPE (held-out EuRoC, vs the never-moving reference scored the same way),
5 of 6 flights improved, −7.1 % (seeds 7–9), −14.8 % TUM-VI rooms 1–4 (the row says it includes the two
tuning rooms), 3.5 MB of 8 MB, 6.6 ms of 20 ms per IMU-second (Linux Docker), 521 tests, 36/36 · 36/36 · 24/24
format checks. Paths and trajectories are labelled *schematic*. The K-2 log card shows abstract bars, not data.

## Rebuilding

Not everything needed is in git:

- **Not committed:** the talking-head recordings and the rendered face track (`hyperframes/assets/face_cut.mp4`, 188 MB, personal footage); the music and SFX files (listed in `CREDITS.txt`); GSAP.
- **GSAP:** `npm i gsap@3.15.0`, then copy `gsap.min.js`, `DrawSVGPlugin.min.js`, `MorphSVGPlugin.min.js`, `MotionPathPlugin.min.js`, `CustomEase.min.js`, `SplitText.min.js` from `node_modules/gsap/dist/` into `hyperframes/assets/lib/`.
- **Pipeline scripts** use absolute paths from the machine they ran on (`/home/claude/vx/...`); edit the paths before reuse. Order: `transcribe_sherpa.py` → `envelope.py` → `cutlist.py` → `render_cut_audio.py` (+ `seam_energy.py`, `verify_cut_asr.py`) → `cut_words.py` → `facecrop.py` → `render_face.py` → voice chain (`voice_chain.txt`, FFmpeg) → `mix.py` → `hf/build.py` → `npx hyperframes render`.
- Speech models: sherpa-onnx Parakeet TDT 0.6B v2 and Whisper medium.en (from the sherpa-onnx GitHub releases).

## Known limitations

- The voice was cleaned with FFmpeg only (high-pass, a notch on the ~174 Hz fan hum, de-esser, gentle
  compression): about 2 dB gain. Adobe Enhance Speech could not be run from the build sandbox.
- Lip sync is frame-locked by construction and the voice sits within 1 ms of the timeline across the film
  (`pipeline/audiosync.py`); visual spot checks at five lip closures agree within the speech model's timing step.
