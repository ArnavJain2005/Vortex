## Facts from the docs that shape Track 3

- The station is stationary and tabletop. Firmware: VL53L0X ToF every 40 ms, HC-SR04 at 15 Hz, MPU6050
  accelerometer only (±2 g, DLPF 44 Hz, 100 Hz), gyro unused. Only semantic values leave the board;
  raw values appear only in `#DIAG` (every 5 s in telemetry as `SENSOR_DIAG`).
- On the accepted station the HC-SR04 is fitted but produced no valid readings in any logged live run
  (`us_ok=0`), so confidence is always LOW. Any plan that uses ultrasonic range anchors needs that fixed
  and checked on hardware first.
- Link: USB serial 115200 only (Windows, kernel32). UDP 47800 receive exists in Unity but the firmware
  has no Wi-Fi/UDP send path. `physxr_unified` has a soft-AP dashboard but is untested.
- Clocks: device `ts` and Unity time are never compared; latency is per-hop only. A tracking channel that
  fuses headset pose with IMU samples needs a new, measured time-sync design.
- Headset: Quest 2 / Quest 3 over PC VR (OpenXR, Quest Link), team-confirmed. Not standalone.
